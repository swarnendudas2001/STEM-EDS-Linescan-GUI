# Extract EDS linescan from STEM hyperspectral datacube

<img width="368" height="464" alt="image" src="https://github.com/user-attachments/assets/e17d5f6d-105c-4284-b036-ecba951b8ac1" />

1. Simply load the .dm3/.dm4 files for your STEM-EDS data (includes combination of the ADF image and Spectrum Image)
2. Input your elements of interest (here we demonstrated on Au NP doped with Bi)
3. Includes Bremsstrahlung background subtraction
4. Interactive way to draw the line for the EDS linescan
5. Control line width to increase signal-to-noise (SNR)
6. Includes smoothing option
7. Save the analysis output as .csv file or save the screenshot of the GUI as .png.
